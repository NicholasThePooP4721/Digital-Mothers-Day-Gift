# How to install
For a complete beginner in coding/github it might be a little hard to execute a python file.

First of all you install the newest python version from the microsoft store. Just search python and install.
After that you just open cmd and type in python to see if that works.

After that you enter
--cd (here you add the current folder you saved the file in--)
once you are in the folder you simply type in
python CustomGift1.4.py
and it should open.
